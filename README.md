# Почта

«Почта» (`haltia-mail`, `io.github.haltia_de.Mail`) — простая программа для одного ящика. Часть среды [Haltia](https://github.com/haltia-de). На планшете она скрыта с домашнего экрана: через неё помощнику уходят отчёты о сбоях, и ей же другие программы передают файлы.

## Как пользоваться

- Вход — адрес и пароль приложения. Серверы IMAP и SMTP программа берёт по домену ящика.
- Папки: «Входящие», «Отправленные», «Корзина». Письмо показывается простым текстом, без картинок из интернета. Вложения можно открыть и сохранить.
- Новое письмо: «Кому», «Тема», текст и файлы. Файл, который другая программа отдала через «Отправить», начинает такое письмо.
- «Исходящие» держат письмо, пока нет сети, и отправляют его, когда сеть появляется.
- «Выйти» стирает пароль и локальную копию писем. Пароль лежит в хранилище `haltia_kit.vault` и в настройки не записывается.

На планшете пункта «Почта» на домашнем экране нет. Открыть её можно из «Настройки → Для помощника → Почта для отчётов».

## Для других программ

Отчёт и любое другое письмо уходят без окна, по D-Bus: имя `io.github.haltia_de.Mail`, объект `/io/github/haltia_de/Mail`, метод `Send`. Ответ приходит сразу, как только письмо сохранено: `sent`, `queued` или `not-configured`. Подробности договора — в `AGENTS.md`.

## Установка

Пакет `haltia-mail` для Alpine и postmarketOS. Из исходников: `sh install.sh` (нужны Python 3, PyGObject с GTK 3 и haltia-kit 2.3.0 или новее).
